A fair exam for enzyme models

Before training a model on enzymes, you have to split them into training, validation and test sets. If test enzymes are secret relatives of training enzymes, the model can ace the test by memorizing. This project builds a split where that can't happen, and measures how well it worked.

The problem

Proteins come in families

Most ML assumes each example is independent. Proteins aren't: they have relatives. A random split scatters each family across train and test, so the test is full of cousins of what the model already saw. The fix is to keep each family together on one side.

Random split

Families are split up. Red links are relatives that cross into the test set.

Group split

Each family stays on one side. No links cross, so the test is a real test.

Four ways two enzymes can be secretly alike

Same shape, different jobs

The biggest shape group is 15 TIM barrels: isomerases, aldolases, synthases and a deaminase. A shared fold doesn't mean shared chemistry, so shape alone can't define "the same active site".

Same active site, different shapes

Zinc metalloproteases (HtpX, FtsH, ADAM) share the HExxH zinc site across 4 different folds. Only Folddisco links them, which is why structure-only splits still leak 3–7% by active site.

Labels are thin

Only 100 of 300 enzymes have annotated active sites, and only 3 of those come from experiments. The rest are inferred from similar proteins.

For the model

What this means once you train something

This project builds and checks the dataset. No model has been trained yet. These are the rules the split implies for the model that comes next.

What the test score means

Can the model handle an enzyme from a family it has never seen? That is harder than a random split, so expect lower scores. Train the same model on both splits: the gap is how much of the "random" score was memorization.

Two tasks the data supports

Per protein: predict the EC class (7 categories). Per residue: predict which amino acids form the active site. That is heavily imbalanced: 1–4 positive residues out of about 400.

Missing is not "no"

200 enzymes have no active-site annotation, which means "unknown", not "has none". Mask them out of a per-residue loss; never train on them as negatives.

Validation vs test

Tune hyperparameters and early stopping on validation as often as you like. Score test once, at the end. Checking it repeatedly quietly turns it into a second validation set.

Small numbers

30 test enzymes means one prediction moves accuracy by 3.3 points. Report bootstrap confidence intervals and results over several split seeds (--seeds).

Pretrained models

Protein language models such as ESM were trained on nearly every known protein, including relatives of this test set. The split can't control that, so state it with any results.

Honest limits

What can still leak

  • Unannotated active sites. 224 enzymes had no usable motif, so a similar but unannotated site goes unseen.
  • Relatives outside the sample. Only these 300 were compared with each other. Swiss-Prot has 266,000 more enzymes.
  • Cutoffs are conventions. 30% identity and TM-score 0.5 are standard choices, not hard boundaries. The 0.55 Å cutoff for 3-residue motifs was tuned on this sample only.
  • The test set is all singletons. Every multi-member family went to training. That is intended, but it is a distribution shift.
  • A few weak leaks remain. In the combined split, three held-out enzymes match a training enzyme over only part of their length (22–26% identity, or TM-score 0.50). One is a real distant relative: RimO and lipoyl synthase are both radical-SAM enzymes. Adding the audit's links to the grouping would remove them.

Run it

Reproduce everything

A few minutes on a laptop. Needs uv, MMseqs2 (Homebrew), and the Foldseek and Folddisco binaries; the README has install commands.

uv venv .venv && uv pip install -p .venv -r requirements.txt
.venv/bin/python scripts/fetch_enzymes.py --n 300 --seed 0   # UniProt sample
.venv/bin/python scripts/cluster_sequences.py               # MMseqs2
.venv/bin/python scripts/fetch_structures.py                # AlphaFold DB
.venv/bin/python scripts/cluster_structures.py              # Foldseek
.venv/bin/python scripts/motif_groups.py --reindex          # Folddisco
.venv/bin/python scripts/make_splits.py                     # splits + audit
.venv/bin/python scripts/build_site_data.py                 # this page's data

The result: results/dataset_manifest.csv, one row per enzyme with its split, its group from each tool, its active-site and structure status, and notes.

Data: UniProt release 2026_03 and AlphaFold DB. Code: github.com/ybai08/swissprot-enzyme-splits.
